# System Health Monitor

A simple Python project to monitor system information and automate basic system administration tasks.

## Features

- Check system information and disk usage.
- Monitor running processes.
- Analyze application log files.
- Check network connectivity.
- Get file and directory information.

## Project Structure

```text
system-health-monitor/
├── main.py
├── system_monitor.py
├── file_manager.py
├── log_analyzer.py
├── process_manager.py
├── network_checker.py
└── README.md
```

## Requirements

- Python 3.8+
- No external dependencies required.

## Usage

Run the following commands:

```bash
python main.py system
python main.py files
python main.py logs --path ./logs
python main.py processes
python main.py network
```
